# Future Sources

Candidate event sources to evaluate and (eventually) build scrapers for. Not
yet wired into `service/data/sources.txt`. Mined from event links in Bay Area
culture newsletters:
- [Devon Youngblood's Substack](https://devonyoungblood.substack.com/) — arts + culture.
- [Same Page SF](https://samepagesf.substack.com/) — literary events (bookstores, readings, lit orgs).

Each still needs a spike to confirm scrapable structured data (JSON-LD / API /
ICS) before a scraper is written — see `CONTRIBUTING.md`. Many venues host
events on a shared ticketing platform (Eventbrite, Luma, Veezi, Posh, Square,
VBO, Tixr, Eventive) — the venue's own site is listed here as the source; a
platform scraper may be the better path for some (noted where relevant).
